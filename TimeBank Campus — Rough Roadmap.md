### TimeBank Campus — Rough Roadmap

```text
Idea Finalization
       ↓
Basic UI Design
       ↓
Login / Sign Up
       ↓
Student Profile
       ↓
Add Skills / Services
       ↓
Browse & Search Skills
       ↓
Request a Service
       ↓
Accept / Reject Request
       ↓
Complete Session
       ↓
TimeBank Token Transfer
       ↓
Ratings & Reviews
       ↓
Transaction History
       ↓
Notifications / Chat
       ↓
Token Purchase (optional)
       ↓
Testing + UI Polish
       ↓
Final App + Documentation
```

**Basic Tech Flow:**

```text
Kotlin + Jetpack Compose
          ↓
      ViewModel
          ↓
     Repository
          ↓
    Room / Firebase
          ↓
   Data + Transactions
```

**MVP first:** Login → Profile → Skills → Request → Complete → Tokens → Review.
Then we add **chat, notifications, token purchase, and other advanced features** if time permits.
